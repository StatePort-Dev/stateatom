# Исходники единого UX-прототипа StatePort

`index.html` — модульная HTML-точка входа.
`style.css`, `app.js`, `engine.js` — Atom, типизированные редакторы и демонстрационная модель.
`extension.css`, `extension.js`, `extension-model.js` — Capture, настройки origins и Action Inspector.
`assets/stateport-mark.svg` — знак StatePort.

Сборка из корня комплекта: `python3 source/build_standalone.py`.
Результат — `../index.html`: одна автономная страница.
Для общей инструкции и ограничений откройте `../README_RU.md`.
