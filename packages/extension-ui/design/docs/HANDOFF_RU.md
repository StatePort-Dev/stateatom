# Handoff: единый исходный комплект

## Состав и приоритет

Это исходники уже собранного интерфейса, а не новая задача на редизайн.
Сохранять выбранный стиль HTML и согласованный принцип: данные, источники и редакторы
на первом уровне; пояснения — по запросу. Не добавлять обязательную LLM для формирования
обычных строк состояния. Settings разделены по точным origins, включая схему и порт.

В `source/app.js` находятся текущие Atom UI и базовый сценарий приложения.
`source/engine.js` содержит UMD-модель подмен для браузера и Node-тестов.
`source/extension.js` расширяет базовый UI через обёртки renderer/functions и общие globals.
Это осознанная структура исследовательского прототипа, не рекомендуемый итоговый
production-компонентный дизайн. Порядок четырёх JS-файлов в `source/index.html` важен.

## Реальные границы

- Редактор JSON, переключатели, состояния подмен и поведение synthetic app работают.
- API-подмена действует на демонстрационную модель, а не на чужую вкладку.
- Capture проходит состояния готовности/записи/review/saved по локальной fixture-модели.
- Saved receipt здесь демонстрационный; не сохранение настоящей State Card.
- Source-map picker хранит выбор файла; не парсит архив и не запускает анализатор.
- Artifact identity comparison проверяется на синтетических метаданных.
- Handlers/hooks отделяют static path от observed demo-event; это не полный hook engine.
- Local explanation — optional template preview. Модель не скачивается и не вызывается.
- Записи пользовательского ожидания и бизнес-контекста не генерируются автоматически.

## Что изменено при упаковке

Шесть файлов UI/моделей/CSS и SVG-ресурс сохранены без изменения содержимого.
Build пишет `index.html`; пути тестов сделаны относительными, browser executable —
настраиваемым. Базовый Atom browser suite теперь запускается на едином HTML; его
проверка title обновлена с v2 на фактический заголовок v3. Проверки поведения не убраны.
Новых production-возможностей при упаковке не добавлялось.

## Проверяемые инварианты при дальнейшей интеграции

Draft не равен delivered; снятое правило не равно восстановленному состоянию;
путь по коду не равен исполненному пути; source maps не равны runtime provenance;
Capture Review не равен Saved; Saved не равен Verified. Не превращать эти различия
в ложные положительные статусы ради красоты интерфейса.
