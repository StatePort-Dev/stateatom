[Project status](docs/status.md) keeps the earlier Phase 2 report separate from the newer verified import and short-loop checks. ## Initial release scope

- One explicitly named target browser and the application stack already best supported by the prototype. Record tested versions; do not infer support for an entire framework from one example.
- A basic browser workflow that does not require an IDE, StatePort Desktop, an account, or a private service.
- A declared deeper analysis workflow that may require an open source-project connection or development instrumentation. Show these requirements before the operation is used.
- A limited set of supported local interventions with defined cleanup and stale-state behavior.
- Evidence saved and exported through the product interface, readable without the original IDE or Desktop connection.

The initial release does not require all six historical deep cases to pass. It requires a useful, reproducible supported scope and an accurate account of the remaining cases. Preserve the original criteria and result history when reporting a new supported subset.
