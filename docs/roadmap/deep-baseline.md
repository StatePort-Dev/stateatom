## Selected new evaluation

`!eligible` → `#p2.disabled`. Control: original **React P1**, unchanged nested
destructuring/alias plus arithmetic → `#p1.text`. These are meaningfully different

execution → relevant transforms/current state → a particular consumed exchange and

nearby timestamps and endpoint-effect trials cannot fill a missing edge.

The next bounded experiment addresses only the first commit boundary. It must not
set `fullPath:true`, claim state/async/cache lineage or reclassify any historical case.

The first remaining full-path gap is **the consumed JSON field versus the current
field read, across the actual cache/state/props alias lifetime**. Native equal-value
cache/Fiber writer controls preserve identities while changing the write history;
they reject an identity-only certificate. Receiver guards remove concrete false
field identities but do not prove all writers absent. Full-field and historical
family results therefore remain **not met / 0 of 6**.

The bounded work item ends with this supported fragment and missing capability, as
allowed by roadmap section 1; it is not a passed milestone. The next architectural
decision needs a trusted compiler-to-script/effect premise for this selected alias
lifetime with competing-producer controls. Adding a new resolver, treating all
compiled bodies as invoked, or accepting missing writers would not satisfy it.
See [latest journal scope](2026-10-18-code-journal-progress.md) and the linked
React/Query/native reports for exact commands and manifests.
