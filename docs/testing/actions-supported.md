Native lookup stays bounded to the selected node, document, html and body,12
registrations. Current finite native Chrome probe returned no parentId; no ancestor
path was fabricated. Other ancestors, window, shadow roots and framework portal/
logical propagation are explicit gaps. A registration is potential context, not
an actual event path. The independent fixture's event log is a semantic control;
Atom itself still reports execution not-observed. Mandatory A05 remains open.

Source forwarding additionally bounds32 flat parameter properties,64 component
references/attributes and16 JSX return/container steps, plus existing depth/cycle/
file/excerpt budgets. Const alone does not establish object-slot immutability.
Source-only relations supply no state/query/parameter ownership certificate.

Each current record retains selected document/node/inspection/run/source identity.
Native metadata has its own optional registration snapshotId/readAt: the extension's
metadata-read time, not the original registration or dispatch time. V1 fields are
additive; legacy payloads are not assigned a current clock. Remote object groups
are released. No new debugger permission or Runtime execution primitive is added.
