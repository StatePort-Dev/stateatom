# Passive input evidence integration

Working implementation contract for U03.2c.3c.1, not a retrospective interview
approval. `input-evidence/1` is admitted by the installed dispatcher/store only
alongside readable Atom and recipient views and explicit removal controls.
Active capture/consent/report creation remains U03.2c.3c.2.

The original report stays first. A collapsed historical input section separates
original selected observation, later editor observation, per-transaction native
acknowledgements or response deliveries, and unknown consumption/effect. Every
retained optional envelope is rendered with its state and friendly transaction/
resource ordinal. Opaque identities and historical locators are advanced details.
No application, source file, model, IDE or linked URL is opened by reading.

Privacy supports whole-packet, four category and per-field omission. No input
replacement is offered. Previously omitted/not-recorded fields cannot be restored.
Base privacy prunes overlaps under the existing composition contract. Source
comparisons and unverified notes preserve the input packet and use the canonical
public component parent; whole-file lineage uses exact original file bytes.
Source-file/finding/options snapshots happen before the first asynchronous hash.
All changed controls invalidate prepared downloads through the existing epoch;
Cancel preserves the original file and typed Developer note.

Existing minimal/reviewed/source profiles keep their meanings and exact bytes.
Stored input files are passive historical claims, never executable drafts/rules,
permissions, replay, undo or proof of a fix. Unsupported/checksum/stale-parent
files are refused without replacing the original.

Visual references: packages/extension-ui/design/README_RU.md,
docs/HANDOFF_RU.md and design/SCREEN_INDEX.md beneath that design directory;
docs/design/extension-ui.md. Use existing Settings disclosures/value rows and
13px body/12px controls, no shared token or primitive changes. The input section
has no supplied prototype counterpart: this necessary extension is a documented
deviation using the existing foundation, not a replacement design. Compare
rendered first viewport/type/layout/controls against supplied HTML/screens;
390/440px, actual 200% zoom, keyboard and reduced motion must be checked.
Screenshots remain candidates pending optional human review.

The private capture intentionally skips browser refresh but must apply the same
five-minute unsaved observation cap as save-diagnostic. Expiry must refuse, not
substitute a current editor value for the original observation.
