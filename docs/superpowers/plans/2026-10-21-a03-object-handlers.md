## Design and scope

Current resolver immediately refuses every member expression. Extend one useful
source-only pattern: a constant lexical object literal with one unambiguous own
data function/method used as the selected native JSX event callback. Named method
labels and source coordinates come from source, with distinct Code-linked edges;
execution remains not-observed. This does not read page properties, execute a
getter, invoke a function or establish current runtime identity.

For an admissible receiver, require a constant local object-literal binding with
no mutation/escape/unsupported use. Reject getters/setters, computed/spread/duplicate
keys and ambiguous receivers; only direct static event-property reads are allowed
for references to that object. An object literal's const binding alone does not
prove its slots immutable. Reject writes, deletes, updates, alias/return/argument/
spread escapes and unsupported member use instead of following arbitrary objects.
Reference to a separate declared handler or useCallback can reuse the existing
lexical resolution and preserve its hook relation. Preserve the source binding's
member expression; do not invent a business name for an anonymous function.

No new UI/token/layout, invocation tracing, broad call graph or generic ownership
framework. Prop forwarding/custom hook/native ancestor/freshness rows remain the
parent A03 task; this increment alone does not complete it. Existing direct/alias/
import/inline/hook/factory/prop/getter/override/unsupported controls stay intact.
