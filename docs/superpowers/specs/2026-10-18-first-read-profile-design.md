# First-render field revision profile

User intent: complete the remaining roadmap autonomously, preserving the original
selected React P2 and separately structured P1 criteria. The authorized automated
acceptance remains agent-operated. Old experiments and frozen candidates stay
unchanged. No general resolver or framework expansion is introduced.

## Decision

Implement one open, reviewed **closed-project effect profile**, followed by a
verifier that joins its Code-linked proof to scoped observations. This is not a
general JS effect engine or native runtime attestation. Exact source/compiled
hashes bind a proof to a version; hashes, scalar equality and an allowlist by
themselves are not the effect proof.

The interval ends at the P1 destructuring/P2 member reads in the first successful
App data-render. Later getQueryData, structuredClone and Row props escapes cannot
be used to reject that earlier interval. Subsequent renders require another proof
and initially remain Unknown. The baseline application and helper source stay
unchanged. The profile cannot turn a callback or competing same-value producer
into HTTP origin.

The broad alternative—instrument all final JS writes/calls/native and implicit
paths—is rejected for this increment: class fields, bound native mutators, eval,
constructor semantics and complete code-drain would constitute a separate effect
engine. Proxy-wrapping, freezing or converting parsed properties to accessors is
also rejected because it changes application semantics.

## Proof obligations

The source proof enumerates account/rules aliases from Response.json consumption
through direct account variable, fresh Query cache retention and direct React
state action until the two particular original reads. It must establish:

1. New QueryClient with no options/custom cache/defaults/subscriptions/mount, no
   earlier account query, and no mutation of the admitted instance/prototypes.
2. Direct object updater, original build/setData identities, no previous query/data;
   replaceData has no custom structuralSharing and replaceEqualDeep(undefined,
   account) returns account without traversing/mutating it.
3. Cache added and query updated notifications have no listeners/observers; no
   notifyManager override, unobserved GC callback or other retained-alias operation
   before these reads. Audit utils, notifyManager, subscribable, removable and
   timeoutManager along with the existing three Query inputs.
4. React null initial state and direct object action, preserved action/update/hook
   identity; no functional/rebased unknown update. No unreviewed DevTools,
   profiling, Refresh or application callback receives Fiber/state before reads.
5. Complete admitted executable graph: final bytes/configuration, not merely a
   matching function marker. Unknown transform/script/frame/context, pending or
   lost code acquisition and prior history deny the profile. The browser-owned
   script collection must finish draining before a claim is accepted.
6. The selected state root, P1 original destructuring or P2 original member event,
   transformation dependency graph, committed host target and browser exchange
   all share compatible page/frame/build/run/update/consumption identities.

The verifier does not evaluate an app expression, function, getter or skipped
branch. It does not claim eternal readonly after a read. Original scalars and later
native descriptors remain separate. A pre-read literal write, even of the same
value, must refuse. A later write does not rewrite the earlier scalar receipt.

## Trust and reporting

Trusted profile/compiled facts come from the open product's declared source/build
and browser acquisition boundaries, never a page-supplied fullPath or arbitrary
boolean. Profiles carry their derivation, exact input identities and checked branch
premises. Page-reported runtime joins remain explicitly instrumented-page evidence.
An imported report is passive historical data and cannot authorize operations.

Actual UI must display Code-linked source/effect proof separately from Observed
runtime joins and call out this first-render/closed-project scope. Incomplete
premises produce Unknown with the specific missing premise. Vue controls and all
other cases remain unchanged. Do not call profile scaffolding a passed full trace.

## Acceptance

Keep unchanged original P2 and P1. Verify direct and bound/native pre-read literal
writers, configured structuralSharing, notifications/subscribers, alternate state
updates, unknown compiled code, context/history loss and mixed identities as
negative controls. Exact same-value controls must remain Unknown. The existing
panel/IDE/experiment/restore/export workflow remains usable; accept a full claim
only through the intended product interface and fresh passive export reader.

This design was independently challenged read-only. The review explicitly allows
audited closed-project proof under the unchanged one-case/control criterion, and
identified the Query callback/React Fiber exposure premises above. It has not
certified implementation or runtime evidence.
