# Browser-owned script-entry acquisition probe

The compiled-content inventory cannot show that a source executed. The next
bounded experiment uses CDP's beforeScriptExecution instrumentation breakpoint in
one fresh main page. Enable before navigation, record actual paused script/context
identities and source, and always resume original execution. Unknown sources,
unsupported realms, source loss and budgets remain explicit; do not block user
code to manufacture a complete proof. No field/ownership certificate is enabled.

Compare original P1/P2 output with/without the observation and test fresh script,
eval and Function construction versus invocation. Compilation-only and observed
entry are different records. If the breakpoint misses a relevant execution kind,
retain the counterexample; never infer complete execution coverage from the name
of the CDP API. Delays can affect scheduling and must be disclosed. No expression,
getter or callback is rerun for extraction. Scope is one fresh controlled page;
whole browser/realm history and source/compiler equivalence remain separate.

Use a separate acquisition harness after existing native checks finish. The real
panel acceptance remains its own evidence. A successful entry observation supplies
one missing fact only, not readonly effects, complete script history or HTTP ancestry.
