# Current open development plugin package

Purpose: make the existing dev plugin's current source available as a reproducible
local archive and check that a separate consumer actually loads its payload. This
does not install a helper, implement a production SDK or qualify new native support.
Autonomous routine packaging choice, not a new approved user-flow or capability.

Reuse existing plugin-only packer (chosen) rather than silently rebuilding7 under
its old name or coupling unchanged Atom/UI/VSIX reissues. Unique metadata8; same
exports/dependencies/peers/profiles/opt-in permissions. Preserve all old bytes.

Exact source/payload map, immutable artifact check, separate offline consumer and
actual resolved dependency paths. Verify packaged entry/default/disabled/refusal and
copied state ledger with late-deref and Unknown controls. No root source fallback.
Existing source tests stay their actual checks, no native/installed proof from pack.
