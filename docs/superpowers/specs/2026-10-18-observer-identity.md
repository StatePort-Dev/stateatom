# Observer identity prerequisite for wrapper contracts

Bounded continuation of the compiled-effect assessment under autonomous roadmap
scope. Fix two actual counterexamples before assessing readonly wrappers: a public
active window.__STATEATOM__ object was accepted as the factory result, and member/
other API method slots could be replaced with functions or accessors. Neither a
helper compiler digest nor the observer's disk hash establishes the actual callee.

Use a private module-owned WeakMap for same-factory instance reuse. Never read a
public global getter to identify an observer. Preserve active mode checks, stop,
fetch/JSON restoration and fresh inactive-instance creation. Freeze only the newly
created inspection API, leaving application objects, prototypes and callbacks
unchanged. Keep public global transport untrusted; this is not runtime attestation,
a readonly certificate or protection from changed runtime source/primordials.

Preselected native controls:

1. Original P2/P1 and semantic getter/error outputs remain unchanged with ordinary
   frozen factory-owned API. Inspect only own descriptors of four observer slots,
   not invocation of app functions or getters.
2. A declared pre-bootstrap public global getter/object cannot be adopted or read
   as a factory identity. Setter publication is separately witnessed.
3. Actual runtime Reflect.set and Reflect.defineProperty replacement/accessor
   attempts fail; replacement functions/getters do not execute.
4. A post-transform modification to the runtime member BODY performs a same-value
   quota write before its marker. The API still has frozen own slots and original
   helper compiled correspondence can hold; runtime content differs and readonly/
   current-field/fullPath remain Unknown/false. A frozen object is not code proof.
5. Retain both helper post-stage writers, operator rewrite and delayed cache clone.

The native markers are declared synthetic control evidence, never product writer
provenance. No call property is assumed readonly and no observer wrapper is stripped
in functionFragment. Exact compiled callee/body/closure effect contracts and full
alias-lifetime coverage remain a separate prerequisite after this identity fix.

Validation: retain RED/green identity controls, full unit suite/build, native controls,
actual connected React panel/IDE/export/reinspection and the short-loop regression
with Vue expected PARTIALs. Reuse unrelated completed checks; native harnesses run
sequentially in new result directories. No publication or old-experiment mutation.
