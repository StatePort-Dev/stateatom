# Product-owned compilation journal (bounded prerequisite)

The separate compiled inventory harness cannot supply product-owned history. Reuse
its fail-closed identity/budget principles in an extension-owned, digest-only CDP
journal. Comparison: the harness has trusted server receipts and exact content
matches; this product step has neither and must not claim source equivalence,
invocation, readonly effects, ownership, field ancestry or response causation.
No new resolver, framework or user-expression execution is allowed.

Store at most 256 script records, 64 contexts, 2 MiB per source and 8 MiB hashed
bytes per navigation epoch. At most eight source requests/hashes are active;
additional eligible IDs queue within the same 256-record bound, without bodies. No compiled bodies, query strings, credentials or data
URLs persist or export. Anonymous/sourceURL/isolated/other-frame code is visible as
a gap to closed-world claims, not silently safe. Late attach, restart, detach,
source failure, pending hashes, context loss and budgets remain explicit. The
journal does not attest to future code or pre-navigation external effects.

Navigation while attached starts a new observation epoch; initial attach is late.
Worker restoration marks interrupted collection. Async source completion stays
bound to its original journal object/run. No late result can attach to a new epoch.
Selection snapshots retain collection ID, generation, run and capture time, with
an explicit independent-observation scope. Subsequent records make that collection
snapshot historical with newer data available; they do not invalidate unrelated
app source or fabricate a dependency. Inspect again captures a newer snapshot.
Selection/navigation/IDE invalidation keeps the existing behavior.

The existing panel and passive diagnostic reader show counts, context boundaries,
coverage limits and snapshot freshness independently of runtime source links. A
journal is available without IDE; imported journal claims authorize no actions.
Automatic UI acceptance must check actual dependency capture, missing earlier
history on late attach, newly compiled code followed by newer inspection, and
reviewed export/fresh passive read. Unit controls include races, restart, limits,
URL redaction, all context kinds and no promotion of page-supplied runtime claims.
