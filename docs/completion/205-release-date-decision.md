existing work. Three substantive uncertainties areA02, L02 and V02. Their results

check/implementation establishes the missing premise. Summing nine speculative
estimates would give false precision.

2. Address V02 measurement prerequisite first, using existing source/fixture contracts.
   A fresh valid measurement would show whether an actual performance fix remains;
   a certificate/setup workaround by itself is not progress toward10%.

   harness or repeated old campaign. Each finite item must end in code/evidence/local
   commit or a precise unresolved input. Source-only preparation is not feature completion.
4. Current-pair host intake/coexistence and paired UI checks reuse the existing host
   implementation. They require the separate host task because this Atom continuation
   explicitly excludes changing that repository. No publication follows automatically.
5. Final clean-install/independent-app/candidate ledger checks use the same immutable
   accepted pair and current supported paths. Historical criteria/results remain intact.

No completed feature is proposed for removal. No performance exception, AI waiver,
fullA02 credit, new Live/production/handoff setting, broader OS support or release
