## Delivered behavior and evidence boundaries

Select a real native target → Actions → Connect source map → import its explicit
local map/release ZIP → View registered listener source. The loaded script is
selected automatically. No IDE, application instrumentation or generated coordinate
entry is required. Runtime derives positions from its own private current native
registration; request fields are only bindingId, snapshotId and canonical contextKey.
Extra client coordinates, script IDs, anchor objects and source text are rejected.

The operation requires read access, owned attached debugger and a current inspection.
It rechecks actual selected backend/document/marker and freshly collected registration
metadata through the existing native DOM queue. It does not call identifySelection,
observeDeep, an application getter/handler, Runtime.callFunctionOn or an IDE bridge.
It matches the fresh event/location/target/options tuple; a removed, changed, ambiguous
or wrong-target listener cannot reuse an old native index. Concurrent inspection,
source/map change, input-edited investigation, cancellation and stale DOM refuse late
text. Refreshed metadata can replace current state; source previews are never cached
in runtime/storage/default diagnostics. Historical saved reports stay unchanged.

The existing map session now consumes genuine locally constructed current anchors
and the indexed read-only provider. Duplicate original names retain their exact
sourceIndex, not first filename match. Exact artifact mapping is Code-linked for
the REGISTERED LOCATION only. An unverified map stays Candidate. Missing source
content yields position only; declared line/column outside available original text
is Unavailable even when artifact bytes match. Manual lookup remains unlinked.
Callback-object identity, invocation, selected property's producer, operands and HTTP
ancestry remain Unknown/not-observed. No new production grant/TTL/cache policy.
