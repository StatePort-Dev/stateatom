## Narrow correction

`refreshElementSnapshot` commits only into the exact captured bundle. If another
read already replaced that bundle in the same tab-state, selected object, run,
inspection generation and source generation, the superseded read keeps the newer
stored result. A typed stale-refresh signal distinguishes this case from native
read failures. A changed context still rejects; an unrelated browser error is
never swallowed. No original expression/getter is evaluated, no authority is
broadened, no app mutation or automatic retry is added.
