## Registered real-model baseline

The fixed24-case synthetic corpus and expected prompt bytes were sealed before
model creation/inference. The actual model campaign used a disposable derivative:
ALL original .26 host bytes unchanged, exactly2 added evaluation-page files. The
adapter forwards availability/create/prompt/destroy to the REAL browser API; no
mocked model or fabricated execution/HTTP/source evidence is involved. This is an
evaluation extension document, not yet installed Atom Explain UX acceptance.

-24 unique corpus cases actually returned LanguageModel.prompt output.
-20 outputs passed the unchanged strict literal-summary/refs/limits validator.
-4 outputs omitted existing evidence IDs(one blocker,no blocker,masking,scalar);
 validation rejected them and displayed the exact deterministic template. No IDs
 were silently filled, invented or accepted with a weaker threshold.
-All24 displayed results equalled their templates: added usefulness0/24.
-Initial native Start/Cancel had trusted activation, real download progress and
 API AbortError; it returned a template. Availability stayed downloading afterward:
 cancellation did not remove or promise removal of browser-managed files.
-Two120s download timeouts returned templates; the third explicit request completed
 download and real inference. First initiation→first inference about302.5s;
 first successful request61.4s, including remaining download/initialization.
-Subsequent23 corpus requests:median4.30s,range2.56–6.04s in this configuration.
 These include the recorded test harness; not universal hardware/performance claims.
-One ADDITIONAL actual inference passed in an extension-document CDP offline context
 with navigator.onLine=false. This is not an OS network-airgap or process-global
 network-capture claim. No remote fallback exists in the provider.
-25 resolved actual sessions received25 destroy calls; aborted creation produced
 no resolved session. This proves scoped API cleanup calls, not browser heap/leak
 acceptance or deletion of downloaded files.

The24 examples do not replace the historical feature-spec gate of at least25,
including5 incomplete/ambiguous and5 malicious/untrusted examples. Approved07 asks
20–30; a later30-case acceptance set can satisfy BOTH. No existing denominator or
historical result is changed. This exploratory baseline is not final acceptance.

Prompt bytes in the receipt are exact builder-produced bytes from registered frozen
facts; source allowlist verified. The forwarding adapter did not independently tap
the prompt argument at the API boundary, so no wire-capture claim is made. Rich
source/names/paths/arbitrary values stay outside the prompt by the existing explicit
projection and prior source controls. The original registered protocol is retained
before adding these post-run qualifications.
