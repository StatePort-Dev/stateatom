## Model contract

The new stateatom.action-evidence/version1 packet references the exact saved v1
diagnostic SHA and retains recorded collector status, bounded dispatch/body/exit
ordinals and explicit missing context. Action identities, function source paths/
coordinates/digests, function names and notes are excluded by default. Explicit
choices include only selected scalar fields; the private review catalogue and
original raw observation never enter public bytes. A filtered/replaced/omitted
identity or source field makes the original context join unverifiable. Fully
included fields must reconstruct the original bounded trace grammar. All records
remain historical untrusted claims, sourceCurrent/executable=false; no handler,
source or current-property consequence is inferred.

Privacy creates a new immutable packet, binds the exact raw parent and permits
only further omission or explicit reviewer redaction. A parent-aware parser rejects
restoring grandparent values; absent parent bytes stay not-checked. Checksums are
content integrity, not trusted authorship or observed execution. Input choices are
snapshotted before awaits; accessors/unknown fields/duplicate JSON/invalid typed
rows and malformed records refuse. No browser/fetch/writer is used.
